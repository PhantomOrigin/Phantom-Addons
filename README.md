# Phantom-Addons
A minecraft QOL mod for Hypixel Skyblock. Primarily features Kuudra features.

## Kuudra Features:
### Stun
- Incorrect Pickobulus Blocker
- Eaten Timer
- Cannon Auto Close
### Dynamic Pearl Waypoints
- Timer Accurate to current angle, not preset
- Change colour on hover
- Customisable Size and Shape
### Miscelaneous
- Auto GFS Toxic/Twilight poison
- Auto Refill Toxic Poison
- Hide Elle Dialogue
- Lava Teleport Blocker
- Fast DPS warning
- Chest Tracker (tracks successes and fails)
- Solo Warning
- Shop Keybinds

## Other Features
- M7 Dragons Auto GFS
- Range Based Explosion Hider
- Lava Colour / Opacity Tools

## KNOWN INCOMPATABILITIES:
Phantom Addons is incompatible with KIC Elle dialogue hider. 
Certain features will not work if you use moveable crate pickup progress bar from either IQ or KIC.
