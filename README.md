# Phantom-Addons
A minecraft QOL mod for Hypixel Skyblock. Primarily features Kuudra features.

Latest Version: 1.6.0
Supported Minecraft Versions: 26.1.2

### Supplies Features
- Supply Beacons
- No Pre Announce
- No Pre Notification
- Crate Priority HUD
- Custom Supply Recovery Message
- Supply Location Announce
- Supply Start Timer
- Supply Hitbox
- Supply Pull Radius
- Supply Pearl Hitbox
- Block Skyblock Menu Clicks
- Dynamic Pearl Waypoints
- Supply Pearl Location Beacons
### Build Features
- Build Progress Tracker
- Announce Fresh
- Fresh Notification
- Build Started Notification
- Build Beacons
### Stun / DPS
- Auto GFS Poisons
- Role Detection
- Incorrect Pickobulus Blocker
- Eaten Timer
- Stun Preview / Waypoint
- Cannon Auto Close
- Fast DPS Warning
- Fast DPS Notification

- Kuudra Highlight
